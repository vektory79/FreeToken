# Опыт Strata / Project Maya: вердикты и указатели (2026-11-15)

Дистиллят в kb (статья + план):
- kb/topics/strata-maya-inference-study.md - обзор движков, таблица совпадений, вердикты.
- kb/cases/offline-coverage-curve/ - ЗАКРЫТ 2026-11-15: гейт KV-стриминга NO-GO
  (VERDICT.md; офлайн кривая C(S): S0=820, +300 слотов = +3.85 п.п. < +5,
  валидация симулятора 0.13 п.п., потолок покрытия 82% - ~15-18% пар
  одноходовые и не кэшируются никаким фондом). План-пакет был TASK.md,
  чек-лист закрыт полностью.

Ключевые вердикты:
- 5 механизмов Strata уже есть в FreeToken: tiers VRAM/RAM/SSD, pcie-frac,
  префилл-оверлап, skip-unpicked префилл, адаптивная LRU-резиденция.
- KV-стриминг Strata (--kv-resident) на нашем риге закрыт NO-GO гейтом
  (см. выше) - реализация не понадобилась. У Maya для GLM его тоже нет
  (DSA-индексер сканирует всю историю - RAM-gather внутрь attention).
- Route affinity Maya: бонус резидентным экспертам в скор выбора; у Maya
  0.2 = +22-25% декода за KL 0.20, 0.05 = +7-11% за KL 0.15. НАМЕРЕНО на
  нашем риге 2026-11-15 (см. память ft-route-affinity-ab): env-крючок
  FREETOKEN_ROUTE_AFFINITY (бонус только на selection-скор `ranked`, веса
  не трогаются), aff 0.05 = +16.9% tok/s (22.5 -> 26.34), hit 35.7 -> 48.9% -
  выше полосы Maya; диффы не закоммичены, рука aff 0.2 и kb-статья были
  в работе на момент записи. Офлайн-кривой не покрывается (смещает сам
  роутинг) - потому и мерилось отдельной рукой с батареей качества.
- Не переоткрывать: MTP (NO-GO, verify M размножает мисс-пары CPU-ноги),
  KV-quant (kv-quant-ab закрыт, fp8 sweet spot), KDA-графы +2.35%, EXPDEC +1.1%.

Why: запрос "ускорение без потери контекста и свободной VRAM"; сравнение с
чужими движками дало 2 живых кандидата: один закрыт гейтом за день без
кернельной работы, второй измерен и превзошел полосу Maya.
How to apply: числа Strata/Maya - их машины, не наш риг; любые новые
ёмкостные рычаги для этого конфига начинать с факта потолка 82% покрытия.
