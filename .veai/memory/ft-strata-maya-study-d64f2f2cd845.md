# Опыт Strata / Project Maya: вердикты и указатели (2026-11-15)

Дистиллят в kb (статья + план):
- kb/topics/strata-maya-inference-study.md - обзор движков, таблица совпадений, вердикты.
- kb/cases/offline-coverage-curve/TASK.md - план-пакет OPEN: офлайн кривая C(S)
  "слоты -> покрытие" из трейса маршрутизации (CPU-only, без GPU), гейт для
  KV-стриминга и ёмкостных рычагов. Гейт: +300 слотов < +5 п.п. покрытия = NO-GO,
  >= +8 п.п. = бриф на прототип. Валидация: симуляция при S0 vs телеметрия,
  порог 2 п.п.; якорь "покрытие 0.50" получен на 0.82/400k, на 0.81/800k не переносить.

Ключевые вердикты:
- 5 механизмов Strata уже есть в FreeToken: tiers VRAM/RAM/SSD, pcie-frac,
  префилл-оверлап, skip-unpicked префилл, адаптивная LRU-резиденция.
- KV-стриминг (--kv-resident, KV в pinned RAM ради слотов) для GLM не сделан
  даже в Maya (DSA-индексер сканирует всю историю - RAM-gather внутрь attention).
  Оценка потенциала: перенос половины KV-квоты 0.81/800k ~ +200-300 слотов
  (слот Q3_K_XL ~10.9 MiB) - оценка, не измерение.
- Route affinity Maya: бонус резидентным экспертам в скор выбора; 0.2 = +22-25%
  декода за KL 0.20, 0.05 = +7-11% за KL 0.15; меняет ответы; офлайн-кривой
  НЕ покрывается (смещает сам роутинг) - мерить отдельной рукой.
- Не переоткрывать: MTP (NO-GO, verify M размножает мисс-пары CPU-ноги),
  KV-quant (kv-quant-ab закрыт, fp8 sweet spot), KDA-графы +2.35%, EXPDEC +1.1%.

Why: запрос "ускорение без потери контекста и свободной VRAM"; сравнение с
чужими движками дало 2 живых кандидата и гейт-план вместо реализации наугад.
How to apply: работа над KV-стримингом/ёмкостными рычагами начинается с
offline-coverage-curve Ф0-Ф3; числа Strata/Maya - их машины, не наш риг.
