### reasoning
The user wants a Python function `is_palindrome(s)` that:
1. Ignores case (so "A" and "a" are treated the same)
2. Ignores non-alphanumeric characters (so spaces, punctuation, etc. are stripped out)
3. Has a docstring

This is a classic problem, often exemplified by "A man, a plan, a canal: Panama" which should return True.

Let me think about the best implementation approach:

**Approach 1: Filter and compare with reversed string**
```python
def is_palindrome(s):
    cleaned = ''.join(ch.lower() for ch in s if ch.isalnum())
    return cleaned == cleaned[::-1]
```

This is clean and Pythonic. It:
- Uses `str.isalnum()` to keep only alphanumeric characters
- Uses `str.lower()` to normalize case
- Compares the cleaned string with its reverse using slicing `
