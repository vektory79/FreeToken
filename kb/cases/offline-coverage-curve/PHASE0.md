# Ф0: аудит телеметрии выбора экспертов

**Вердикт: трейса per-step нет; нужна точечная инструментировка. Выполнена.**

## Что уже есть (проверено по коду)

- `collect_stats` (`OffloadMoeCache`, python/freetoken/moe/offload_cache.py):
  кумулятивные missing/fetched/active/calls - агрегат и по каждому слою
  (`decode_miss_stats`, `decode_miss_stats_per_layer`). Накопление device-side,
  графобезопасно (captured-граф переигрывает `+=` на реальном роутинге).
- `collect_decode_freq`: гистограмма пар (слой, эксперт) и
  `decode_routing_stats` (оракул стационарного LRU по частотам). Честна только
  в eager (`--cuda-graph-max-bs 0`): host-scatter не переигрывается под
  CUDA-графом.
- Периодический сброс счётчиков (`scheduler.decode_stats_line`) включается
  ТОЛЬКО CLI-флагом `--moe-collect-stats`. Без него счётчики кумулятивны с
  загрузки - это делает телеметрию совместимой с полной реплей-симуляцией.

## Чего нет

- Последовательность активных пар (слой -> эксперты) по шагам декода. LRU -
  порядок-зависимая политика (recency, очерёдность вытеснений); из агрегатов и
  гистограмм она не восстанавливается, а оракул `decode_routing_stats`
  стационарен и верхней границей динамики не является.

## Решение (реализовано в рамках Ф1)

- T1-драйвер декод-кампании (`kb/harness/decode-research/driver/`)
  расширен env-флагом `FREETOKEN_DR_ROUTES=1`: в eager каждый вызов
  `OffloadMoELayer._decode_routed` копирует `(layer_id, topk_ids)` в
  device-буфер ДО перезаписи id слотами (буфер содержит сырой роутинг, никогда
  слоты); периодический дамп `routes_<tag>.json` (каждые 64 шага + закрытие
  окна + exit) вместе с метой кеша: pool_sizes, pool_of_layer, slot_bytes по
  слоям, фракции fetch, locked/unpinned, n_replay_steps (0 = eager).
- Роутинг инвариантен к режиму графов и к фонду слотов: overflow-пары
  вычисляются на CPU теми же весами, маршрутизатор резидентность не видит
  (route affinity в проде нет). Поэтому eager-трейс валиден для симуляции
  прод-политики при любом S. Greedy (`temperature: 0, top_k: 1`) в раннере
  исключает семплинг-недетерминизм (требование TASK.md).

## Сопутствующие правки драйвера

- В режиме routes периодический дамп переписывает и `stats_<tag>.json`
  (телеметрия кумулятивна до последнего дампа, а не только до закрытия окна).
- Броня сохранена: каждый хук в try/except, баг драйвера деградирует в no-op.

Обоснование не переносить якорь "покрытие ~0.50" со старого конфига 0.82/400k -
в TASK.md; фонды слотов конфигов разные (у 0.82/400k пул ~1059-1167, у
0.81/800k S0 = 820 по бут-логу Ф1, см. VERDICT.md по завершении Ф3).
