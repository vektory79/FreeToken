# Вердикт: гейт ёмкостных рычагов

**KV-стриминг (перенос части KV-квоты в RAM ради слотов экспертов) закрыт
NO-GO без реализации.** По правилу гейта из TASK.md: +300 слотов дают
**+3.85 п.п.** покрытия C(S) при пороге NO-GO < +5 п.п. и GO >= +8 п.п.

## Конфиг-якорь и фонд слотов (бут-лог)

- `--moe-cache-auto resolved moe_cache_size=820` - **S0 = 820 слотов**,
  стабильно во всех пяти бутах кампании (страницы KV дрейфуют 12519-12526
  с десктоп-фоном, слоты - нет).
- 3 пула форм-групп GGUF: **[20, 39, 761]** (unified scope, equal split,
  `pool_policy._split_equal`): 2 слоя IQ3_XXS/Q6_K, 1 слой IQ4_XS/Q6_K,
  39 слоёв IQ3_XXS/IQ4_XS. L=42, E=288, top_k 8; locked/unpinned слоёв нет.
- Фракции fetch из benchbw-профиля v6 (файл 2026-11-10): 28.4% / 24.7% /
  29.7% по группам; байты слота 10.375 / 12.688 / 15.062 MiB
  (`engine._moe_layer_slot_bytes`).
- KV 801216-801664 токенов fp8 = 4.76 GiB; prefill overlap отключён планом
  (820 < 2*288).

## Метод

- **Ф1 (трейс)**: boot точного конфига в eager, fill 64k (radix-reuse),
  greedy-декод 768 токенов с `ignore_eos` (без него EOS обрезал декод на
  545 - длина при temp0 недетерминирована, готча харнесса). T1-драйвер в
  режиме `FREETOKEN_DR_ROUTES=1` записал **770 шагов x 42 слоя** (32340
  вызовов): (слой, top-8 экспертов) на каждый шаг декода + мету кеша.
  Роутинг инвариантен к фонду слотов и режиму графов (overflow-пары считаются
  на CPU теми же весами), поэтому eager-трейс валиден для симуляции
  прод-политики при любом S. Пара шумовых шагов от readiness-проб присутствует
  и в трейсе, и в телеметрии - симулятор реплеет всё согласованно.
- **Ф2 (реплика)**: numpy-симулятор - точная host-копия
  `_ensure_experts_hybrid_kernel`: timestamp-LRU слотов пула, выбор фетчей
  BY_RECENCY (recency desc, id asc), min-wait округление `frac * misses`,
  кап `min(missing, frac*misses, E, pool - hits)`, жертвы argmin(usage)
  (ties - младший слот), overflow -> CPU, recency всех активных обновляется
  после выбора. Состояние холодное на старте трейса; step-счётчик монотонный.
- **Sweep**: {S0, S0+100..+600, 2*S0, 12096} с ре-сплитом слотов той же
  политикой (`split_equal` кросс-чекнут против `pool_policy` на 30 случайных
  пулах).

## Валидация при S0 - PASS

- C по телеметрии бута **0.4913**, C симуляции **0.4927** - дельта
  **0.13 п.п.** при пороге 2.0 п.п.
- Максимум дельты miss_rate по отдельному слою - **0.31 п.п.** (все 42 слоя
  в таблице результатов).
- Замечание: якорь Strata-исследования "покрытие ~0.50" воспроизвёлся и на
  этом конфиге (0.49), хотя фонд слотов другой (820 против ~1059-1167 у
  0.82/400k) - совпадение значений, не перенос якоря.

## Чтение (проекция, не оракул)

- Вердикт принят по C(S), как требует TASK.md. Проекция на tok/s - только
  через модель стоимости шага (kb/topics/moe-hybrid-cost-model.md): шаг
  упирается в CPU-ногу (перелив ~1.77 GiB/шаг при ~26.9 GB/s эффективных
  на стеке 2026-09; свежий benchbw v6 даёт те же фракции). +300 слотов
  снимают **-7.6% байт CPU-ноги** (-0.134 GiB/шаг); 2*S0 - -18%; потолок
  (недостижимые 12096 слотов) - -65%.
- Верхняя граница выигрыша +300 слотов - единицы процентов декода ДО вычета
  новой стоимости (RAM-gather ячеек KV внутри DSA-attention - то, что Maya
  не стала строить), и она сравнима с межбутным шумом конфига (~7%).
- Кривая выпуклая: предельные п.п. на 100 слотов падают
  (1.41 -> 1.24 -> 1.20 -> 1.16 -> 1.03 -> 0.95 -> 0.94 -> +2.2 на 2*S0).
- **Потолок покрытия 82%** (медиана шага 85%): ~15-18% пар экспертов -
  одноходовые (не повторяются в окне), их не обслужит из VRAM никакой фонд
  слотов. Это общий предел ВСЕХ ёмкостных рычагов, не только KV-стриминга.

## Гейт

+300 слотов = +3.85 п.п. < +5 п.п. -> **NO-GO**: KV-стриминг для этого
конфига не окупает кернельной работы (RAM-gather внутри DSA-attention).
Промежуточные и большие переносы (S0+500 = +5.0 п.п., 2*S0 = +9.2 п.п.)
требуют отдать KV больше половины квоты и остаются ниже кривой шума в
проекции - владельцу нет смысла их рассматривать без нового запроса
нагрузки (длиннее окно / другой профиль маршрутизации).

## Что этот вердикт НЕ закрывает

- **Route affinity** (Maya): смещает сам роутинг, офлайн-кривой по трейсу
  прод не покрывается - мерить отдельной рукой (env-флаг на железе +
  батарея качества), после этого вердикта. Это теперь главный живой
  кандидат из Strata/Maya-исследования.
- Рычаги, не меняющие фонд слотов (prefill overlap, чанки, CPU-нога) -
  вне скоупа кейса.
