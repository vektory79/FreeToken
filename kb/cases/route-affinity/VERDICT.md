# Вердикт полного гейта route affinity

## Пороги (утверждены в [TASK.md](TASK.md) до измерений, не менялись)

- Качество значения X: доля пар «не хуже базы» >= 85% И 0 новых фактических
  ошибок на промптах с проверяемым ответом И NIAH не ниже базы - 2 п.п.
- Скорость: медиана tok/s >= база + 10%.
- Победитель: максимум медианы среди прошедших качество. Плато: большее
  значение в пределах ~7% шума меньшего -> берётся меньшее.

## Исполнение

13 бутов (лестница x2 + 3-й бут победителя), сериально, census чист перед
каждым, session-tier L2 restore давал fill 64k за ~4.4 c. Все автопроверки
арифметики 5/6 во всех руках (arith_bin - постоянный контроль обреза
бюджета). Ф2-суд выполнен на тех же бутах; слепой парный протокол:
детерминированная перетасовка A/B, метки в отдельном ключе, вердикты
записаны до раскрытия, пересуд 10% пар со сторонами наоборот.

## Суд качества (слепой парный, рубрика: корректность / связность / инструкция)

Доля «не хуже базы» = (tie + X-лучше) / N; строгая доля (tie засчитывается
базе) приведена рядом. Самосогласованность пересуда: 45/45 пар.

| value | буты суда | N | base/tie/X | «не хуже базы» | строгая |
|---|---|---|---|---|---|
| 0.05 | r1 | 56 | 3/50/3 | 94.6% | 5.4% |
| 0.1 | r1+r2 | 112 | 9/99/4 | 92.0% | 3.6% |
| 0.15 | r1 | 56 | 2/49/5 | 96.4% | 8.9% |
| 0.2 | r1+r2 | 112 | 8/100/4 | 92.9% | 3.6% |
| 0.3 | r1+r2+r3 | 168 | 12/151/5 | 92.9% | 3.0% |

Все значения прошли порог 85%. Проверяемые ответы (b20-b23, арифметика,
NIAH): ни одной новой фактической ошибки; два обреза бюджета (b23 у 0.3 в
r2/r3 - пошаговое умножение не влезает в 128 токенов, вычисления верные,
ответа нет) классифицированы как артефакты измерения. NIAH пулом: 259/260
(единственный промах - флейк бюджета, см. выше).

Паттерны: NIAH без деградации на всех значениях и глубинах 40-60k; проза
и декод-768 дают двусторонний разброс (победы есть у обеих сторон во всех
значениях - нет систематической потери); мульти-turn на 0.3 дважды из трёх
бутов прошёл полную цепочку 73->219->169->338 с русской сводкой, у базы
таких прогонов нет. Артефакт `<|user|>` в 768-продолжении (ignore_eos
прокалывает шаблон чата) присутствует во ВСЕХ руках, включая базу, -
свойство пробы, не рычага.

## Вердикт: GO-CLI

- 0.3 прошёл оба порога: качество 92.9% >= 85%, скорость +112.1% >= +10%.
- Плато-правило не срабатывает: 0.3 против 0.2 = +17.1% > ~7% шума.
- Рекомендация: значение 0.3 как opt-in ручка (CLI-флаг поверх env);
  дефолт остаётся 0 - решение владельца по материалам этого файла.
- Диффы остаются env-гейтами без коммита; мерджи требуют повторной
  проверки `FREETOKEN_ROUTE_AFFINITY` в обоих файлах.

## Отклонения/уточнения методики (честная запись)

1. Формула «не хуже базы» операционализирована как (tie + X-лучше)/N;
   строгая доля с tie=базе публикуется рядом (консервативная трактовка
   TASK.md сохранена для претензий на превосходство).
2. Обрезы бюджета (NIAH 0.1-r1, b23 0.3-r2/r3) классифицированы как
   артефакты измерения: finish=length, искомый контент найден/верен,
   ответ оборван. Они не считаются новыми фактическими ошибками.
3. Качество 0.05 и 0.15 оценено на первом буте (r1); автопроверки их r2
   чисты (NIAH 20/20, проверяемые b24 - PASS). Пограничных значений среди
   них нет (94.6% и 96.4%).
4. История мульти-turn собирается из message.content (у reasoning-парсера
   пуст) с фолбэком на склейку reasoning - артефакт «утечки мысли»
   симметричен для всех рук.
5. Hit-строки парсятся только до конца декода (улучшение против первого
   замера, где окно не ограничивалось).

## После гейта (тот же день): решение владельца

Владелец решил: сделать CLI-флаг, дефолт 0.0. Реализовано вместо env-крюка
(единый источник истины - флаг): `--route-affinity` в `server/args.py` ->
`EngineConfig.route_affinity` (валидация >= 0) -> инъекция в `ModelConfig`
рядом с `moe_strategy`/`decode_target` (engine.py, блок `if is_moe:`, boot-строка
`route affinity ...` при > 0) -> `Glm5NextSparseBlock` читает `config.route_affinity`
вместо `FREETOKEN_ROUTE_AFFINITY`. Хarness гейта переведён на флаг
(`run_arm.py`). Дефолт 0.0 = прод не затронут.
