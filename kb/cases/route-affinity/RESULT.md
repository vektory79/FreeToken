# Route affinity: первый замер (A/B 0 / 0.05 / 0.2)

**Механика работает и даёт больше, чем у Maya.** Бонус резидентным экспертам
в скор выбора маршрутизатора поднимает долю попаданий слот-кэша с 35.7% до
48.9% (0.05) и 73.6% (0.2), декод растёт с 22.54 до 26.34 tok/s (+16.9%) и
38.55 tok/s (**+71.0%**). У Maya на их стеке было +7-11% при 0.05 и +22-25%
при 0.2 - у нас эффект втрое сильнее при том же значении коэффициента.

| arm | affinity | tok/s | p50 мс/шаг | hit, % | оценка C* | арифметика | проза изменилась |
|---|---|---|---|---|---|---|---|
| aff000 | 0 (база) | 22.54 | 43.9 | 35.7 | ~49% | 5/6 | - |
| aff005 | 0.05 | 26.34 | 37.4 | 48.9 | ~62% | 5/6 | 4/4 |
| aff020 | 0.2 | **38.55** | 25.6 | 73.6 | **~81%** | 5/6 | 4/4 |

\* C = 1 - (miss - fetch)/active по строкам "MoE decode" лога; fetch = frac x
miss. Сравни с офлайн-кривой
[offline-coverage-curve/VERDICT.md](../offline-coverage-curve/VERDICT.md):
потолок покрытия ЛЮБОГО фонда слотов - 82%. **Affinity при 0.2 доходит до
~81% покрытия без единого лишнего слота VRAM** - он бьёт все ёмкостные
рычаги разом, потому что меняет сам запрос (какие эксперты выбираются), а не
ёмкость под запрос.

## Реализация (исследовательский env-гейт)

- `FREETOKEN_ROUTE_AFFINITY=<float>` (дефолт 0 - прод не затронут).
- `kernel/triton/moe_router.py`: в `_router_triton_kernel` бонус
  `ROUTE_AFFINITY x resident` добавляется ТОЛЬКО в selection-скор `ranked`
  (sigmoid + bias); веса `activated` - unbiased-скор выбранного - не
  трогаются (семантика Maya: меняется выбор, не вес).
- `models/glm5_next/moe.py`: маска резидентности =
  `slot_for_id[layer] >= 0` из offload-кеша (LRU предыдущего шага, читается
  под графом на каждом реплее - динамично и графобезопасно). Prefill
  естественно инертен: materialize очищает строки слотов каждый чанк.
- Ограничение: работает для offload/hybrid бэкендов; softmax-роутеры
  affinity не получают.

## Метод

Три сериальных бута точного прод-конфига (графы, БЕЗ eager), fill 64k
(session-tier restore), radix-reuse greedy-декод 768 токенов с ignore_eos,
steady tok/s по дельтам SSE-кадров; hit-рейты - из строк "MoE decode"
(`--moe-collect-stats`, 19 интервалов на руку); батарея - 6 арифметических
промптов (авто-проверка) + 4 прозаических (тексты сохранены, сравнение с
базой дословное). Ответы - в arm_*.json каталога кампании.

## Цена качества (предварительно!)

- Арифметика 5/6 во всех трёх руках - упал ОДИН И ТОТ ЖЕ промпт
  (arith_bin, двоичный перевод) по одной и той же причине: пошаговое деление
  не влезает в 96-токенный бюджет. Деградации нет.
- Проза: 4/4 текстов изменились уже при 0.05 (смещение роутинга = смещение
  ответов - ожидаемо). В коротких образцах различия - уровень перефразирования,
  связность сохранена; это НЕ вердикт о качестве.
- **Не измерено**: длинный контекст, большая батарея (24 промпта кампании
  GGUF), KL дрейф, агрегированные суждения. До прод-ручекки нужна полная
  батарея качества - желательно с LLM-судьёй на парах ответов
  (база vs affinity).

## Оговорки замера

- По одной руке на значение (шум межбутный ~7%): +71% и +16.9% далеко выше
  шума, но точечные значения - не медианы. Для гейт-решения повторить 3 руки
  на значение.
- Бонус применяется и в батчах > 1 (маска общая на слой) - на сервере bs=1.
- Взаимодействие с group-topk (если включён) - бонус входит в групповой
  скоринг до фильтра групп; для этого конфига групп нет.
- knоb env-гейтнут и не закоммичен; до CLI-флага - только после батареи
  качества.
